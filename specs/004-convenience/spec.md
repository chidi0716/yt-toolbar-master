# 004 便利功能

狀態：草稿，待專案擁有者確認

## 目的

在初版加入四項專案擁有者指定的便利功能：

1. 鎖定畫質
2. 下載時自動嵌入資訊
3. 依時間範圍下載影片或音訊
4. 複製帶時間的連結

工具列外框見 [`001-toolbar`](../001-toolbar/spec.md)，下載功能見 [`002-downloads`](../002-downloads/spec.md)，觀看輔助見 [`003-viewing-tools`](../003-viewing-tools/spec.md)。

## 1. 鎖定畫質

### 使用情境

使用者希望每部影片都以 1080p 播放，不想每次手動到 YouTube 的設定齒輪切換，也不希望 YouTube 自動降畫質。

### 功能需求

- **FR-1**：在「更多（⋮）」面板加入「鎖定畫質」項目，右側是下拉選單，選項為：
  - 關閉（預設，交給 YouTube 自動決定）
  - 最高可用畫質
  - 2160p、1440p、1080p、720p、480p
- **FR-2**：選定後，每部影片開始播放時自動切換到該畫質。影片沒有該畫質時，使用低於它的最高畫質；例如鎖定 1080p 但影片最高只有 720p，就用 720p。
- **FR-3**：播放途中 YouTube 自動改變畫質時，擴充功能要切回鎖定的畫質。
- **FR-4**：使用者從 YouTube 自己的設定齒輪手動改畫質時，尊重使用者的選擇，這部影片不再強制切換；換到下一部影片時恢復鎖定。
- **FR-5**：設定會被記住，換頁與重新開啟瀏覽器後仍然生效。
- **FR-6**：鎖定開啟時，「更多」按鈕不需要顯示開啟狀態；但「更多」面板中該項目要顯示目前選擇的畫質。

## 2. 下載時自動嵌入資訊

### 使用情境

使用者下載 MP3 後用音樂播放器開啟，希望看到封面、歌名和頻道名稱；下載影片後，希望在播放器裡能直接跳章節。

### 功能需求

- **FR-10**：經由橋接程式下載的影片與 MP3，預設自動嵌入：
  - 封面：影片縮圖，MP3 用作專輯封面，MP4 用作影片縮圖；
  - 基本資訊：標題、頻道名稱（作為演出者）、上傳日期、影片網址；
  - 章節：影片有章節時一併嵌入。
- **FR-11**：設定頁的「下載」區加入「嵌入封面、章節與影片資訊」開關，預設開啟。
- **FR-12**：檔案格式不支援某項嵌入時（例如 WEBM 不支援嵌入封面），略過該項，不得讓下載失敗。
- **FR-13**：依時間範圍下載（見第 3 節）時，章節只保留落在該範圍內的部分，並依新的起點調整時間。若難以正確調整，可以改為不嵌入章節，但其他資訊照常嵌入。
- **FR-14**：嵌入的資訊只來自 YouTube 提供的影片資料，不得連到其他服務查詢歌曲資訊。

## 3. 依時間範圍下載影片或音訊

### 使用情境

使用者只想要一部長影片裡的某一段，例如 10 分 20 秒到 12 分 05 秒，下載成影片檔或音訊檔。

### 功能需求

- **FR-20**：「影片」面板的畫質清單上方加入「時間範圍」區塊，操作方式與 002 MP3 面板完全相同：
  - 區間滑桿；
  - 「開始」「結束」輸入框；
  - 「與播放器同步」開關，以及「設為目前時間」按鈕。

  兩個面板使用同一個元件，外觀與行為一致。
- **FR-21**：時間範圍預設為整部影片，此時不做裁切，下載速度與原本相同。
- **FR-22**：時間範圍不是整部影片時：
  - 畫質清單中的檔案大小改為依比例估算，並加上「約」；
  - 點任一畫質，就下載該畫質在這段時間內的影片；
  - 檔名加上時間範圍，格式與 MP3 相同（例如「標題 [ID] 10m20s-12m05s.mp4」）。
- **FR-23**：裁切後的影片開頭必須能正常播放，不能有黑畫面或聲音不同步。為此允許重新編碼裁切點附近的畫面，因此裁切下載比整部下載慢；第一次使用裁切時，面板要顯示一行說明「裁切需要額外處理時間」。
- **FR-24**：MP3 面板維持 002 的時間範圍功能不變。
- **FR-25**：時間範圍不合法時的處理與 002 FR-22 相同：輸入框標示錯誤，畫質清單的項目停用。
- **FR-26**：「影片」與「MP3」面板各自記住自己的時間範圍；換到另一部影片時都重設為整部影片。

## 4. 複製帶時間的連結

### 使用情境

使用者想把影片「從現在這個時間點開始」分享給朋友，或貼到筆記裡。

### 功能需求

- **FR-30**：工具列左組在「截圖」右邊加入「連結」按鈕（面板按鈕）。001 FR-6 的按鈕順序與說明面板要一併更新。
- **FR-31**：連結面板提供三個選項，每個選項一行，點了就複製並在面板上顯示「已複製」約 2 秒：
  1. **目前時間的連結**：`https://youtu.be/<影片ID>?t=<秒數>`，秒數取播放器目前時間並無條件捨去；
  2. **Markdown 格式**：`[影片標題（01:23）](https://youtu.be/<影片ID>?t=83)`，時間格式在一小時以上時為 時:分:秒；
  3. **不含時間的連結**：`https://youtu.be/<影片ID>`。
- **FR-32**：面板每一行同時顯示預覽，也就是實際會複製的文字（過長時中間以「…」省略）。預覽中的時間隨播放進度更新。
- **FR-33**：目前時間是 0 秒時，選項 1 與 3 的結果相同，不加 `?t=0`。
- **FR-34**：複製失敗時（例如瀏覽器拒絕剪貼簿存取），面板顯示錯誤，並改為顯示可以手動選取複製的文字框。
- **FR-35**：連結一律使用 `youtu.be` 短網址，並移除播放清單等其他參數。

## 非功能需求

- **NFR-1**：鎖定畫質不得造成播放中斷或明顯卡頓；切換畫質時允許 YouTube 本身的短暫緩衝。
- **NFR-2**：複製連結與鎖定畫質不需要橋接程式；嵌入資訊與裁切下載需要。

## 驗收條件

- [ ] 鎖定 1080p 後打開有 4K 的影片，播放畫質為 1080p；打開最高只有 720p 的影片，播放畫質為 720p。
- [ ] 鎖定後手動在 YouTube 齒輪改成 480p，這部影片維持 480p；換下一部影片恢復 1080p。
- [ ] 選「關閉」後，YouTube 恢復自動決定畫質。
- [ ] 下載 MP3 後，用系統音樂播放器開啟，可以看到封面、標題、頻道名稱。
- [ ] 下載有章節的影片，用支援章節的播放器（例如 VLC、IINA）開啟，可以看到章節。
- [ ] 關閉「嵌入」設定後下載，檔案中沒有封面與章節。
- [ ] 下載 WEBM 不會因為無法嵌入封面而失敗。
- [ ] 影片面板設定 00:01:00–00:01:30，下載 720p，得到約 30 秒、開頭正常、聲音同步的 MP4。
- [ ] 時間範圍為整部影片時，下載結果與未裁切相同，且沒有額外的處理時間。
- [ ] 連結面板三種格式都正確；播放到 83 秒時，Markdown 為 `[標題（01:23）](https://youtu.be/ID?t=83)`。
- [ ] 從播放清單中打開的影片，複製的連結不含播放清單參數。
- [ ] Chrome、Firefox 上都符合以上各項。
