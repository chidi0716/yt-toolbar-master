# 010 實測回饋修正（第一批）

狀態：已記錄，排定下次修改時一起實作（2026-10-25，專案擁有者提出）。

## 一、「更多」中的功能可以加到工具列

- **FR-1**：編輯工具列時，「更多」面板中的開關功能（切換分頁時暫停、自動播放、只播聲音、滑鼠滾輪調音量、隱藏留言）也列為工具，可以顯示在工具列、調整順序或隱藏，規則與 006 的其他工具相同。
- **FR-2**：這些功能在工具列上以按鈕呈現，按一下切換開關，按鈕顯示目前狀態（與深色模式等開關按鈕相同）。
- **FR-3**：預設版面不變（這些功能預設仍在「更多」）；隱藏時照舊在「更多」中操作。設定頁「工具列」區同步列出。

## 二、一鍵下載預設關閉

- **FR-10**：設定頁「一鍵下載」改為**預設關閉**（009 FR-1）。關閉時點「影片」或「MP3」只打開面板，由使用者選擇後按「下載」。開關、預設畫質與 009 的其他行為不變。
- **FR-11**：已安裝並儲存過這個設定的使用者維持原本的選擇；只有沒有設定過的使用者採用新的預設值。

## 三、時間範圍重設

- **FR-20**：影片與 MP3 面板的「時間範圍」旁新增「重設」按鈕，一按回到整部影片（開始 0、結束為影片長度）。範圍已經是整部影片時按鈕停用。

## 四、數字輸入框的外觀

- **FR-30**：「循環播放」面板「重複整部影片 N 次」等數字輸入框，不使用瀏覽器內建的上下箭頭（隱藏原生調整鈕）。改為輸入框兩側的「−」「＋」圓形按鈕，外觀與面板其他按鈕一致（YouTube 的顏色變數、懸停效果），跟隨深淺色。
- **FR-31**：「−」「＋」按住時連續增減；到達最小或最大值時對應按鈕停用；仍可直接輸入數字與使用鍵盤上下鍵。
- **FR-32**：專案中其他使用數字輸入框的地方（例如時間範圍的輸入框）一併檢查，同樣不顯示瀏覽器內建的上下箭頭。

## 驗收條件

- [ ] 編輯工具列時，「只播聲音」等「更多」中的功能可以拖到工具列；完成後工具列上出現該按鈕，按下可切換，狀態正確。
- [ ] 重設工具列後，這些功能回到「更多」。
- [ ] 全新安裝：點「影片」或「MP3」只打開面板，不會開始下載；在設定頁開啟「一鍵下載」後才會直接開始。
- [ ] 調整時間範圍後按「重設」，回到整部影片；整部影片時「重設」停用。
- [ ] 循環次數輸入框沒有瀏覽器內建的上下箭頭，改為「−」「＋」按鈕；Chrome 與 Firefox、深淺色外觀一致。
