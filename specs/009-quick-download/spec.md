# 009 一鍵下載與右鍵下載

狀態：已確認（2026-10-24）

## 目的

把「下載影片／MP3」從「開面板 → 選畫質 → 按下載」簡化成**點一下**；在首頁、搜尋結果等清單上**不用點進影片**就能下載。

## 功能需求

### 一、一鍵下載

- **FR-1**：設定頁「下載」區新增「一鍵下載」開關，**預設開啟**。
- **FR-2**：新增「預設影片畫質」：最高畫質、2160p（4K）、1440p（2K）、1080p（預設）、720p、480p；以及「預設影片格式」：MP4（相容性最好，預設）、不限格式（最高畫質可能是 WEBM）。
  - 選擇規則與鎖定畫質（004）相同：影片有這個畫質就用它；沒有時選比它低的最高畫質；全部都比它高時選最低的。
  - MP4 時依 002 FR-13 的 MP4 組選擇（2K 以上沒有 H.264 時為 AV1／VP9 合併的 MP4）。
  - 同一個畫質有多個幀率時，選最高幀率。
- **FR-3**：MP3 使用 002 FR-20 的位元率設定（預設 192 kbps，記住上次選擇）。
- **FR-4**：一鍵下載開啟、且小幫手可用時，點工具列的「影片」或「MP3」：
  1. 面板打開，直接顯示這次下載：影片標題、使用的畫質（例如「1080p60 MP4，約 320 MB」）或位元率，以及進度。讀取影片資訊時顯示「準備中…」。
  2. 面板上有「改用其他畫質」（MP3 為「改用其他位元率」）：取消這次下載並顯示原本的完整選項清單（含時間範圍等）；以及「取消」。
  3. 其他行為（嵌入資訊、檔名、下載資料夾、完成通知）與一般下載相同。
- **FR-5**：同一部影片的同一種下載（影片或 MP3）正在進行時，再點一次只打開面板顯示這個下載，不會重複下載；已經下載完成時，顯示完成狀態與「再下載一次」。
- **FR-6**：無法一鍵下載的情況（直播中、首播尚未開始、需要登入或會員限定等）：面板依 002 顯示說明，不自動開始。
- **FR-7**：工具列「影片」與「MP3」按鈕的提示文字標明點下去會發生什麼，例如「一鍵下載：1080p MP4」「一鍵下載：MP3 192 kbps」。
- **FR-8**：一鍵下載關閉時，行為與目前完全相同（先選再下載）。

### 二、尚未安裝小幫手時

- **FR-10**：小幫手尚未安裝時點「影片」或「MP3」，面板顯示 008 的安裝引導，**不記住、也不自動開始**這次下載。
- **FR-10a**：每次點「影片」或「MP3」打開面板時，都**重新偵測**小幫手（不使用先前「未安裝」或「缺少元件」的結果）。因此裝好後回到瀏覽器再點一次按鈕，就會依一鍵下載設定直接開始（FR-4），或顯示選項清單。
- **FR-11**：面板一直開著、在背景偵測到小幫手已可使用時（008 FR-1 的自動偵測，或「重新檢查」），顯示「小幫手已安裝完成」：
  - 一鍵下載開啟：顯示一個「開始下載（1080p MP4）」按鈕（MP3 為「開始下載（MP3 192 kbps）」），按下後依 FR-4 開始；
  - 一鍵下載關閉：切換成選項清單（目前的行為）。

### 三、右鍵下載

- **FR-20**：在 YouTube 頁面上，對**影片連結**（例如首頁、搜尋結果、側邊推薦、播放清單中的影片縮圖或標題）按右鍵，選單出現：
  - 「下載影片（1080p MP4）」：括號內為目前的預設畫質與格式；
  - 「下載 MP3（192 kbps）」。
  - 兩個選項放在以擴充功能名稱為標題的子選單中（瀏覽器的預設做法）。
- **FR-21**：只在連結指向單一影片時出現（`/watch?v=`、`youtu.be/`、`/shorts/`）；連結帶有播放清單參數時只下載該影片。頻道、播放清單本身的連結不出現。
- **FR-22**：右鍵下載一律使用 FR-2、FR-3 的預設值，不受「一鍵下載」開關影響。
- **FR-23**：開始時顯示系統通知「開始下載：〈影片標題〉」（取得標題前先顯示影片 ID），完成或失敗時依 002 的通知。下載同時出現在所有 YouTube 分頁工具列的下載清單中，可以取消。
- **FR-24**：小幫手尚未安裝時，顯示系統通知「下載影片需要先安裝小幫手」，點通知打開設定頁的「下載」區（含 008 的安裝引導）。
- **FR-25**：設定頁「下載」區新增「在影片連結的右鍵選單顯示下載選項」開關，預設開啟；關閉時移除選單項目。
- **FR-26**：右鍵選單的文字跟隨 007 的介面語言；預設畫質或語言改變時立即更新。

## 權限

- 新增 `contextMenus`（Firefox 同名）。只用來在 YouTube 頁面的影片連結上新增選單項目；安裝與更新時**不會**顯示額外的權限警告。plan 3.2 與 constitution 第 4 點的權限清單同步更新。

## 驗收條件

- [ ] 全新安裝（一鍵下載預設開啟）：在 1080p 影片點「影片」，不用選擇就開始下載 1080p MP4；在只有 720p 的影片得到 720p。
- [ ] 預設畫質設為「最高畫質」、格式「不限格式」：4K 影片得到 2160p（最高畫質只有 WEBM 時為 WEBM）。
- [ ] 點「MP3」直接以 192 kbps 開始下載；在完整面板改成 320 後，下次一鍵下載使用 320。
- [ ] 一鍵下載進行中按「改用其他畫質」：這次下載被取消、暫存檔被刪除，顯示完整選項清單。
- [ ] 下載中再點一次「影片」不會重複下載。
- [ ] 直播中的影片點「影片」：顯示說明，不自動開始。
- [ ] 一鍵下載關閉：行為與 002 相同。
- [ ] 沒有小幫手時點「影片」→ 照引導安裝 → 回到瀏覽器：面板顯示「小幫手已安裝完成」與「開始下載」按鈕，不會自動開始；按下後開始下載。
- [ ] 同上，但安裝前先收起面板；裝好後再點一次「影片」：立即重新偵測並直接開始下載（不需要按「重新檢查」，也不會顯示舊的「未安裝」畫面）。
- [ ] 已安裝小幫手但缺少 ffmpeg：補裝後再點一次「影片」，立即可以下載。
- [ ] 首頁影片縮圖按右鍵 →「下載影片」：出現開始通知，工具列下載清單出現這個下載，完成後通知。
- [ ] 播放清單中的影片連結按右鍵下載：只下載該影片。
- [ ] 頻道連結、一般網頁（非 YouTube）的連結：右鍵選單沒有下載選項。
- [ ] 沒有小幫手時右鍵下載：出現通知，點通知打開設定頁的安裝引導。
- [ ] 關閉「右鍵選單」開關後，選單項目消失；切換介面語言後，選單文字改變。
- [ ] Chrome、Firefox 安裝或更新後沒有出現新的權限警告。
