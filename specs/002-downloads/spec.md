# 002 下載功能

狀態：草稿，待專案擁有者確認

## 目的

讓使用者從工具列左組的按鈕下載目前影片的影片檔、MP3、縮圖、字幕，或擷取目前畫面。

影片、MP3、字幕的下載由使用者電腦上的 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 與 [ffmpeg](https://ffmpeg.org) 執行；擴充功能只負責介面，透過瀏覽器的原生訊息（Native Messaging）機制與一支本機「橋接程式」溝通。縮圖與截圖不需要橋接程式。

工具列外框與面板的共用行為見 [`001-toolbar`](../001-toolbar/spec.md)。

## 名詞

- **橋接程式**：本專案提供、安裝在使用者電腦上的小程式。瀏覽器啟動它、透過原生訊息傳送指令，它再呼叫 yt-dlp 與 ffmpeg。
- **未連線狀態**：瀏覽器找不到橋接程式，或橋接程式找不到 yt-dlp／ffmpeg。

## 使用情境

1. 使用者點「影片」按鈕，看到這部影片所有可下載的畫質與檔案大小，點一列就開始下載，完成後檔案出現在下載資料夾。
2. 使用者點「MP3」，選 192kbps，把時間範圍拖成 01:30–03:45，按「下載」，得到只有那一段的 MP3。
3. 使用者點「縮圖」，選最高畫質，得到縮圖圖片。
4. 使用者點「字幕」，選「中文（台灣）」與 SRT 格式，得到字幕檔。
5. 使用者看到喜歡的畫面，點「截圖」，得到目前畫面的 PNG。
6. 使用者還沒安裝橋接程式就點「影片」，面板說明需要安裝什麼、怎麼安裝，安裝後按「重新檢查」即可使用。

## 功能需求

### 共通

- **FR-1**：直播中與尚未開始的影片，影片、MP3、字幕面板顯示「直播與尚未開始的影片無法下載」，不顯示選項。
- **FR-2**：影片、MP3 面板開啟時（字幕面板見 FR-44），若處於未連線狀態，顯示：
  - 必要元件為橋接程式、yt-dlp、ffmpeg、deno（yt-dlp 取得 YouTube 完整格式所需的 JavaScript 執行環境）；安裝提示一次列出全部缺少的元件（macOS：`brew install yt-dlp ffmpeg deno`；Windows：`winget install yt-dlp.yt-dlp Gyan.FFmpeg DenoLand.Deno`）。
  - 缺少的元件（橋接程式、yt-dlp 或 ffmpeg）；
  - 依目前作業系統（macOS／Windows）顯示對應的安裝步驟，連到本 repo README 的安裝章節；
  - 「重新檢查」按鈕。
- **FR-3**：下載開始後，工具列對應按鈕上顯示進度（例如圓形進度環），面板內顯示百分比、速度、剩餘時間與「取消」按鈕。
- **FR-4**：同一時間可以有多個下載；面板內列出目前這部影片正在進行的下載。
- **FR-5**：下載完成時顯示瀏覽器通知，內容包含檔名，點通知會在檔案總管／Finder 中顯示該檔案。
- **FR-6**：下載失敗時，面板與通知顯示易懂的錯誤原因（例如「網路中斷」「影片需要登入」「磁碟空間不足」「yt-dlp 版本過舊，請更新」），並提供「重試」。
- **FR-6a**：橋接程式的錯誤代碼對應的使用者訊息（中英文），至少包含：
  - `YTDLP_NOT_FOUND`／`FFMPEG_NOT_FOUND`：缺少元件，顯示 FR-2 的安裝說明
  - `YTDLP_OUTDATED`、`VERIFICATION_REQUIRED`：「YouTube 有變動，請更新 yt-dlp」，附更新按鈕
  - `LOGIN_REQUIRED`：「這部影片需要登入才能觀看，目前不支援」
  - `VIDEO_UNAVAILABLE`、`LIVE_NOT_SUPPORTED`、`FORMAT_UNAVAILABLE`、`NO_SUBTITLES`：對應的簡短說明
  - `NETWORK`、`TIMEOUT`：「網路連線問題，請重試」
  - `DISK_FULL`、`PERMISSION_DENIED`：「無法寫入下載資料夾」，附開啟設定頁
  - `TOO_MANY_JOBS`：「同時下載數已達上限（8 個）」
  - `INTERRUPTED`、`UNKNOWN` 與其他：「下載失敗」，附重試；詳細代碼只寫進 console
- **FR-6b**：沒有百分比的進度（例如裁切下載由 ffmpeg 處理時）顯示為不確定進度。
- **FR-7**：使用者關閉 YouTube 分頁不會中斷已開始的下載。
- **FR-8**：檔名預設為「影片標題 [影片ID].副檔名」，移除作業系統不允許的字元。MP3 有裁切時，檔名加上時間範圍，例如「標題 [ID] 01m30s-03m45s.mp3」。

### 影片

- **FR-10**：面板標題為「下載影片」，下方是畫質清單，從高到低排列。
- **FR-11**：每列顯示四欄：
  1. 容器格式（例如 MP4、WEBM）；
  2. 解析度（例如 2160p、1080p60）；
  3. 畫質標籤：2160p 以上為「4K」（4320p 為「8K」）、1440p 為「2K」、1080p 為「1080」、720p 為「HD」，其餘不顯示標籤；
  4. 檔案大小（例如 147.1 MB）；只有估計值時前面加「約」；未知時顯示「—」。
- **FR-12**：清單只列出「影像加聲音」的完整結果。對於只有影像的格式，自動搭配最佳聲音，大小顯示兩者相加。
- **FR-13**：預設只列出 MP4 結果（相容性最好）；2K 以上沒有 H.264 時，以 AV1（否則 VP9）合併成 MP4 列在主清單，並加註「AV1：部分播放器不支援」（VP9 時寫 VP9）。面板底部有「顯示更多格式」可展開 WEBM 等其他格式。
- **FR-14**：點任一列立即開始下載，不再跳出確認。
- **FR-15**：畫質清單上方有「時間範圍」區塊，可以只下載其中一段，見 [`004`](../004-convenience/spec.md) 第 3 節。

### MP3

- **FR-20**：面板內容由上而下：
  1. 「MP3 位元率」下拉選單：64、128、192、256、320 kbps，預設 192 kbps，並記住上次選擇；
  2. 「時間」區間滑桿，兩個把手分別代表開始與結束，下方顯示 00:00 與影片總長；
  3. 「開始」「結束」兩個輸入框，格式為 時:分:秒，可直接輸入，與滑桿雙向同步；
  4. 「與播放器同步」開關；
  5. 底部按鈕：「釘選面板」（次要按鈕）與「下載」（主要按鈕）。
- **FR-21**：預設範圍為整部影片。範圍等於整部影片時不做裁切。
- **FR-22**：輸入的時間不合法（格式錯誤、超出影片長度、開始晚於結束）時，輸入框標示錯誤，「下載」按鈕停用。
- **FR-23**：「與播放器同步」開啟時：
  - 拖動任一把手，播放器跳到該時間點，方便確認位置；
  - 面板上出現「設為目前時間」的小按鈕，分別放在「開始」「結束」旁，按下即把該端點設為播放器目前時間。
- **FR-24**：「釘選面板」的行為依 001 的 FR-13。

### 縮圖

- **FR-30**：面板列出 YouTube 提供的縮圖尺寸（例如 1280×720、640×480、480×360、320×180），每個尺寸有預覽小圖；不存在的尺寸不列出。
- **FR-31**：點任一尺寸即下載該圖片，格式維持 YouTube 提供的原始格式（JPG 或 WebP）。
- **FR-32**：縮圖下載不需要橋接程式，在未連線狀態也能使用。

### 字幕

- **FR-40**：面板列出可用的字幕語言，分為「上傳的字幕」與「自動產生的字幕」兩組，自動產生的字幕以圖示標記。
- **FR-41**：可選擇檔案格式：SRT（預設）、VTT、純文字（TXT，只有文字沒有時間碼）。
- **FR-42**：沒有任何字幕時顯示「這部影片沒有字幕」。
- **FR-43**：清單最上方預設選中與瀏覽器語言相同的字幕；沒有則選影片原始語言。
- **FR-44**：字幕下載**優先由擴充功能直接完成，不需要橋接程式**：從 YouTube 頁面本身提供的字幕清單取得字幕，並在擴充功能內轉換成 SRT、VTT 或 TXT 後存檔。只有在直接下載失敗時（例如 YouTube 要求額外驗證），且已安裝橋接程式，才改由 yt-dlp 下載；未安裝時顯示錯誤並說明安裝橋接程式可改善。
- **FR-45**：字幕直接下載的檔案存到瀏覽器的預設下載位置（與縮圖、截圖相同）；改由橋接程式下載時，存到設定頁指定的下載資料夾。

### 截圖

- **FR-50**：點「截圖」按鈕立即擷取播放器目前顯示的影片畫面（不含 YouTube 的控制列、字幕或疊加資訊），以原始影片解析度存成 PNG。
- **FR-51**：檔名為「影片標題 [影片ID] 時間點.png」，例如「標題 [ID] 01m02s.png」。
- **FR-52**：擷取成功後，按鈕短暫顯示完成提示；因瀏覽器限制無法擷取時，顯示錯誤提示。
- **FR-53**：截圖不需要橋接程式。

### 設定頁

- **FR-60**：設定頁有以下下載相關設定：
  - 下載資料夾：預設為系統的「下載」資料夾，可以改成其他資料夾；
  - 檔名格式：提供預設格式與兩三個預設選項（不開放任意 yt-dlp 範本，避免注入參數）；
  - 「嵌入封面、章節與影片資訊」開關，預設開啟（見 [`004`](../004-convenience/spec.md) 第 2 節）；
  - 連線狀態：顯示橋接程式、yt-dlp、ffmpeg 是否可用與版本號，以及「重新檢查」按鈕；
  - 「更新 yt-dlp」按鈕：若 yt-dlp 是透過套件管理工具安裝（例如 Homebrew、winget），改為顯示對應的更新指令。

### 橋接程式

- **FR-70**：橋接程式只接受以下種類的指令，其餘一律拒絕：檢查狀態、取得影片資訊與可用格式、取得字幕清單、開始下載、取消下載、查詢進度、在檔案總管中顯示檔案、開啟系統的選擇資料夾視窗、更新 yt-dlp。
- **FR-71**：所有指令以「影片 ID」指定影片，橋接程式自行組出 YouTube 網址；不接受任意網址。影片 ID 必須符合 YouTube 影片 ID 格式（11 碼英數字、`-`、`_`）。
- **FR-72**：格式、位元率、時間範圍、字幕語言、檔案格式都必須經過驗證（白名單或明確的格式檢查）後才傳給 yt-dlp；不得把使用者輸入直接拼接成命令列。
- **FR-73**：下載資料夾必須是存在、可寫入的資料夾；檔名不得包含路徑分隔字元或跳出資料夾的 `..`。
- **FR-74**：橋接程式只允許本擴充功能呼叫（透過原生訊息設定檔中的 `allowed_origins` 與 `allowed_extensions` 限定）。
- **FR-75**：橋接程式不得開啟任何網路連接埠，也不得與 YouTube 以外的服務通訊（yt-dlp 自我更新除外）。
- **FR-76**：提供 macOS 與 Windows 的安裝腳本，負責：
  - 安裝橋接程式；
  - 為 Chrome 與 Firefox 註冊原生訊息設定檔（macOS 寫入使用者層級資料夾，Windows 寫入目前使用者的登錄機碼，不需要系統管理員權限）；
  - 檢查 yt-dlp、ffmpeg 是否存在，沒有時印出安裝方式（macOS：Homebrew；Windows：winget）。
- **FR-77**：提供對應的解除安裝腳本，移除所有安裝腳本建立的檔案與登錄機碼。

## 非功能需求

- **NFR-1**：影片面板從開啟到顯示畫質清單，一般網路下不超過 5 秒；超過 1 秒時顯示載入中。
- **NFR-2**：同一部影片的資訊在面板之間共用，不重複向 yt-dlp 查詢；換到另一部影片時才重新查詢。
- **NFR-3**：橋接程式在 macOS 與 Windows 上不需要使用者另外安裝 Python、Node.js 等執行環境（yt-dlp、ffmpeg 除外）。
- **NFR-4**：橋接程式的記錄檔只寫在使用者的本機資料夾，不包含 cookie 或任何帳號資訊。

## 驗收條件

- [ ] 未安裝橋接程式時，影片／MP3／字幕面板顯示安裝說明；縮圖與截圖仍可使用。
- [ ] 執行安裝腳本後按「重新檢查」，面板正常顯示內容（macOS、Windows 各測一次）。
- [ ] 一部有 4K 的影片，畫質清單包含 2160p「4K」、1440p「2K」、1080p「1080」、720p「HD」，大小合理，由高到低排列。
- [ ] 下載 1080p 以上的影片，得到有聲音的 MP4，可在系統預設播放器播放。
- [ ] MP3 選 320kbps、範圍 00:01:00–00:02:00，得到約 60 秒、320kbps 的 MP3。
- [ ] MP3 輸入「00:99:00」或開始晚於結束時，下載按鈕停用。
- [ ] 開啟「與播放器同步」後拖動把手，播放器跟著跳轉。
- [ ] 縮圖面板只列出實際存在的尺寸，下載的圖片尺寸正確。
- [ ] 有自動字幕的影片，字幕面板分組正確；下載的 SRT 時間碼正確；選 TXT 時沒有時間碼。
- [ ] 截圖得到與影片原始解析度相同、不含控制列的 PNG。
- [ ] 下載途中關閉 YouTube 分頁，下載仍完成並收到通知。
- [ ] 下載途中按「取消」，下載停止且不留下不完整的檔案。
- [ ] 直播影片的下載面板顯示無法下載。
- [ ] 送給橋接程式一個不在白名單的指令、非法影片 ID、含 `../` 的檔名，全部被拒絕（以自動化測試驗證）。
- [ ] 解除安裝腳本執行後，橋接程式與註冊資料全部移除。
- [ ] Chrome、Firefox 上都符合以上各項。

## 不在本次範圍

- 不需要橋接程式的影片或音訊下載（純插件下載）：需修改 constitution 第 3 點，列為可能新增的項目，見 [`BACKLOG.md`](../BACKLOG.md)。

- 播放清單或頻道的批次下載。
- 需要登入的影片（會員限定、私人、年齡限制）——顯示錯誤訊息即可；列為後續擴充，見 [`ROADMAP.md`](../ROADMAP.md)。
- Linux 支援。
- 上架 Chrome 線上應用程式商店。
