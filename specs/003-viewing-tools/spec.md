# 003 觀看輔助功能

狀態：草稿，待專案擁有者確認

## 目的

工具列右組提供改善觀看體驗的功能。這些功能完全在擴充功能內完成，不需要橋接程式。

工具列外框與面板的共用行為見 [`001-toolbar`](../001-toolbar/spec.md)。

## 共通需求

- **FR-1**：除非另有說明，每個功能的開關狀態都會被記住，下次打開影片頁時自動套用。
- **FR-2**：功能開啟時，對應的切換按鈕顯示「開啟」狀態（見 001 FR-9）。
- **FR-3**：YouTube 換頁後，已開啟的功能在新影片上繼續生效。
- **FR-4**：任何功能失效（例如 YouTube 改版找不到元素）時，不得影響影片播放與 YouTube 其他功能。
- **FR-5**：工具列被關閉（彈出視窗的「啟用」關掉或按 ✕）時，所有觀看輔助功能一併停止並還原頁面；記住的設定保留，重新啟用時再套用。深色模式例外：關閉時不把 YouTube 主題改回去。

## 深色模式（切換按鈕）

- **FR-10**：按下按鈕的效果，必須與使用者自己在 YouTube「外觀」選單中選擇「深色主題」或「淺色主題」**完全相同**，包括：
  - 已登入時，YouTube **帳號的外觀設定**跟著改變（在其他裝置或重新登入後也是新主題）；
  - 整頁所有區塊（含頂端搜尋列）顏色正確；
  - 重新整理、換頁、重新開啟瀏覽器後都維持。
- **FR-11**：做法是由擴充功能代替使用者操作 YouTube 自己的「外觀」選單（已登入時在頭像選單內，未登入時在設定選單內）並選擇對應項目。操作過程中，這些選單不得被使用者看見或閃現。切換的速度與是否重新載入頁面，與 YouTube 自己的選單相同，擴充功能不另外加快或修改。
- **FR-12**：擴充功能不另外記住深色模式狀態，也不自行修改主題 cookie 或頁面主題屬性。按鈕狀態永遠反映頁面目前的實際主題；使用者從 YouTube 選單切換時，按鈕跟著更新。
- **FR-13**：YouTube 外觀設定為「使用裝置主題」時，按鈕狀態依目前實際顯示的主題；按下按鈕後改為明確的深色或淺色主題。
- **FR-14**：深色模式不受 FR-5 影響：工具列關閉時不改變 YouTube 的主題。
- **FR-15**：找不到 YouTube 的外觀選單或選項時（例如 YouTube 改版，或其他擴充功能接管了主題），不做任何修改；按鈕提示改為說明，例如「找不到 YouTube 的外觀選項。若安裝了會改變主題的擴充功能（例如氛圍光），請將其主題設定改為跟隨 YouTube。」提示顯示時間足夠閱讀（約 6 秒或滑鼠移開為止）。console 記錄失敗的步驟（選單按鈕、外觀項目、深色／淺色選項）。不得退回修改 cookie 或頁面屬性的做法。
- **FR-16**：本節取代先前所有做法（只切換頁面屬性、改偏好後重新載入、偏好加屬性同時切換），原因見 QUESTIONS Q12、Q14、Q16、Q20。

## 劇院模式（切換按鈕，燈泡圖示）

- **FR-20**：開啟時，播放器以外的頁面區域（頂端列、側欄與推薦影片、影片標題與說明、留言等）都變暗到幾乎看不見（約 90–95%），頁面背景變成黑色，讓畫面只剩影片。深色與淺色主題下效果都要明顯。
- **FR-20a**：播放器與工具列**完全不得被遮蓋或變暗**：亮度正常，播放器上的所有控制項（播放、進度列、音量、設定選單、全螢幕等）與工具列按鈕、面板都能正常點擊。
- **FR-21**：點任何變暗的區域或按 Esc 可關閉。
- **FR-22**：此功能不記住狀態；每次打開影片頁預設關閉。
- **FR-23**：與 YouTube 自己的「劇院模式」（加寬播放器）互不干擾，兩者可以同時使用。

## 子母畫面（切換按鈕）

- **FR-30**：開啟時使用瀏覽器原生的子母畫面，影片在獨立的小視窗中播放。
- **FR-31**：使用者從子母畫面視窗本身關閉時，按鈕狀態同步變成關閉。
- **FR-32**：瀏覽器不支援原生子母畫面時（例如部分 Firefox 設定），按鈕停用並在提示文字中說明原因。
- **FR-33**：此功能不記住狀態。

## 浮動播放器（切換按鈕）

- **FR-40**：開啟後，當使用者往下捲動、播放器捲出畫面時，播放器縮小並固定在畫面右下角繼續播放；捲回播放器原位置時恢復原狀。
- **FR-41**：浮動中的播放器可以用滑鼠拖到畫面其他角落，放開時自動貼齊最近的角落；位置會被記住。
- **FR-42**：浮動中的播放器右上角有 ✕，按下後暫時回到原位置，直到下次捲動離開播放器。
- **FR-43**：浮動播放器寬度約為視窗寬度的 25%（最小 320px），維持影片比例。
- **FR-44**：只用 CSS 與擴充功能內建的程式實作，不引入任何外部函式庫。
- **FR-45**：劇院模式開啟期間，浮動播放器暫停作用：不因捲動或版面變化而浮出；若開啟劇院模式時播放器正在浮動，先回到原位再進入劇院模式。關閉劇院模式後，浮動播放器恢復正常判斷。浮動播放器按鈕的開關狀態不受影響。
- **FR-46**：浮動播放器只依「使用者捲動造成播放器原位置離開畫面」來決定是否浮出；其他功能或 YouTube 自身造成的版面變化（例如劇院模式、YouTube 劇院模式切換、側欄展開）不得讓播放器跳到錯誤位置或變成錯誤大小。

## 循環播放（面板按鈕）

- **FR-50**：面板提供兩種模式（單選）：
  1. **重複整部影片 N 次**：輸入 1–99 的次數，或選「無限」；
  2. **循環片段**：與 002 MP3 面板相同的區間滑桿與「開始」「結束」輸入框，影片播到結束時間時跳回開始時間。
- **FR-51**：面板有「開始循環」與「停止」按鈕；循環進行中，面板顯示「已播放 X 次」。
- **FR-52**：循環進行中，按鈕顯示開啟狀態。
- **FR-53**：換到另一部影片時循環自動停止；此功能不記住狀態。

## 更多（⋮，面板按鈕）

面板以清單呈現以下開關，每項左側為圖示與名稱、下方一行灰色小字說明、右側為開關。

- **FR-60 切換分頁時自動暫停**：開啟後，切換到其他分頁或視窗最小化時影片暫停；回到這個分頁時，只有原本是被這個功能暫停的影片才會自動繼續播放。
- **FR-61 自動播放下一部**：直接控制 YouTube 本身的「自動播放」開關，狀態與 YouTube 介面同步。
- **FR-62 純音訊模式**：開啟後，播放器畫面改為顯示影片縮圖，聲音照常播放。（本功能只隱藏畫面，不保證節省頻寬，並在說明文字中寫明。）
- **FR-63 滑鼠滾輪調整音量**：開啟後，游標在播放器上滾動滾輪可調整音量，每格 5%，並在播放器中央短暫顯示目前音量；游標不在播放器上時，滾輪照常捲動頁面。
- **FR-64 隱藏留言**：開啟後隱藏留言區；關閉時恢復。

## 功能組合

- **FR-90**：觀看輔助功能可以任意組合同時開啟，組合時不得出現播放器位置錯亂、被遮住、尺寸異常或工具列消失。已知需要特別處理的組合：劇院模式＋浮動播放器（FR-45）。
- **FR-91**：與其他常見 YouTube 擴充功能共存時（例如會改變主題或在影片周圍加光暈的擴充功能），本擴充功能的功能失敗時要說明原因，不得讓 YouTube 頁面出錯，也不得與對方反覆搶奪同一個設定。

## 驗收條件

- [ ] 已登入、外觀為深色時按按鈕：整頁（含搜尋列）變成淺色，YouTube 頭像選單的「外觀」顯示「淺色主題」，重新整理後仍是淺色；再按一次回到深色。未登入、外觀為淺色、使用裝置主題時也各測一次。
- [ ] 切換過程中看不到 YouTube 的選單閃現。
- [ ] 從 YouTube 選單切換主題時，按鈕狀態同步。
- [ ] 劇院模式開啟後，播放器以外的區域都變暗（深色、淺色主題各測一次）；播放器與工具列亮度正常，播放器控制列、設定選單、工具列面板都能點擊；點變暗區域或 Esc 關閉。
- [ ] 子母畫面可開啟，從小視窗關閉時按鈕狀態同步。
- [ ] 浮動播放器在捲動時出現於右下角，可拖到其他角落並記住位置，重新整理後位置仍正確。
- [ ] 循環「3 次」播完第 3 次後停止；循環片段 00:10–00:20 會一直在這段重複。
- [ ] 切換分頁時影片暫停、回來時繼續；原本就暫停的影片回來時不會自動播放。
- [ ] 自動播放開關與 YouTube 自身開關同步。
- [ ] 純音訊模式顯示縮圖、有聲音。
- [ ] 滾輪在播放器上調整音量，在播放器外捲動頁面。
- [ ] 隱藏留言開啟後重新整理，留言區仍隱藏。
- [ ] 先開浮動播放器（不捲動）再開劇院模式：播放器維持原位、大小正常，工具列可見；捲動時不浮出。關閉劇院模式後往下捲，浮動播放器正常浮出。
- [ ] 播放器正在浮動時開劇院模式：播放器先回到原位，再進入劇院模式。
- [ ] 安裝並將其他擴充功能的主題設為固定深色時，按深色模式按鈕顯示說明原因的提示，頁面沒有錯誤。
- [ ] Chrome、Firefox 上都符合以上各項。

## 不在本次範圍

- 觀看時搜尋其他影片。
- 自訂工具列按鈕順序與顯示。
