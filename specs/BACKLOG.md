# 可新增功能清單（Backlog）

這裡收集**還沒寫成規格**的功能點子。專案擁有者挑選後，規格方再寫成正式規格（例如 00X-xxx/spec.md），並從本清單移除或標註「已採用」。

較大的方向性項目（例如登入後下載、Linux 支援）記在 [`ROADMAP.md`](./ROADMAP.md)。

## 欄位說明

- **位置**：依 constitution 第 7a 點，「工具列」放觀看時隨手切換的功能，「設定頁」放設定一次就一直生效的偏好。
- **做法**：
  - `CSS`：只靠在 `<html>` 加 class 與樣式（constitution 第 7 點，最便宜）
  - `程式`：需要內容腳本或頁面橋接腳本
  - `橋接`：需要本機橋接程式與 yt-dlp
- **來源**：
  - `A`：公開的 YouTube 擴充功能功能清單（該專案未標示授權，只參考功能名稱，採 clean-room）
  - `B`：參考用的第三方下載擴充功能（見 CLEANROOM.md）
  - `C`：規格方推薦
- **推薦**：⭐ 表示規格方建議優先考慮。

### 純插件下載的評估

專案擁有者選擇目前採「混合」方案（縮圖、截圖、字幕由擴充功能直接下載；影片與 MP3 需要 yt-dlp）。若之後要讓擴充功能自己下載影片或音訊：

- **取得下載網址是主要難點**：YouTube 的串流網址需要解密、需要解碼限速參數、常需要通過機器人驗證取得權杖，網頁版播放器也越來越常改用新的串流格式（SABR）。可使用開源函式庫 youtubei.js（MIT），但解密與驗證必須執行 YouTube／Google 從網路下載的程式碼。
- **必須修改 constitution 第 3 點**：在完全隔離、沒有任何擴充功能權限的沙盒頁面中，只允許執行 YouTube／Google 官方網域的程式碼。
- **合併（1080p）**：畫面與聲音分開，需在瀏覽器內重新封裝成 MP4（ffmpeg.wasm 約 25MB，或較輕量的 JavaScript 封裝函式庫）；受瀏覽器記憶體限制，超過約 1 小時的影片可能失敗。純音訊與 360p 不需要合併。
- **維護成本高**：YouTube 每次調整防護都要等函式庫更新，再重新打包、重新送 Mozilla 簽署；yt-dlp 則通常只需更新 yt-dlp。
- **建議形式**：若採用，做成設定頁中預設關閉的實驗性功能，失敗時建議安裝 yt-dlp。

## 不建議採用

| 功能 | 來源 | 原因 |
|---|---|---|
| 擋影片廣告、隱藏贊助影片與周邊商品 | A | YouTube 持續對抗擋廣告工具，維護成本高，帳號可能被警告；專門的擋廣告擴充功能做得更好 |
| QR code 下載到手機 | B | 本專案的下載在本機處理，手機掃描後無法取得檔案 |
| 其他網站的 YouTube 連結旁加下載按鈕 | B | 需要在所有網站執行，違反 constitution 第 4 點 |
| 透過額外桌面程式下載 4K／8K | B | yt-dlp 已可下載，不需要另外的桌面程式 |
| 透過外部網站的下載或轉檔服務（例如 MP3） | B | 影片會送到第三方服務，違反 constitution 第 2 點；yt-dlp 已可在本機轉檔 |
| 跳過業配片段、顯示倒讚數 | C | 需要連到第三方服務，違反 constitution 第 2 點；若要採用，須先將原則改為「使用者自行開啟的選用功能可例外」，預設關閉 |
