### Install / update

- **Chrome:** unzip `yt-toolbar-master-{{version}}-chrome.zip`, then in `chrome://extensions` turn on **Developer mode** and click **Load unpacked**. To update, unzip over the same folder and click reload.
- {{firefoxSteps}}
- **Video and MP3 downloads:** run the command shown in the Video or MP3 panel. It updates itself.

Step-by-step guide: [README](https://github.com/chidi0716/yt-toolbar-master/blob/main/README.md#install).

## 繁體中文

{{highlightsZh}}
### 安裝／更新

- **Chrome**：解壓 `yt-toolbar-master-{{version}}-chrome.zip`，在 `chrome://extensions` 開啟「開發人員模式」並按「載入未封裝項目」。更新時解壓覆蓋同一個資料夾，再按「重新載入」。
- {{firefoxStepsZh}}
- **下載影片與 MP3**：執行「影片」或「MP3」面板顯示的指令，之後會自動更新。

詳細步驟：[README](https://github.com/chidi0716/yt-toolbar-master/blob/main/README.zh-TW.md#安裝)。
